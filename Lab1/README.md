# Laboratorio 1 - Criptografía y Seguridad en Redes
Informe correspondiente al Laboratorio 1.

## Contenido

   * `Informe_Lab_1.pdf`: informe final del laboratorio.
   * `cesar.py`: programa de cifrado César.
   * `stealth_ping.py`: transmisión de caracteres mediante paquetes ICMP.
   * `mitm_decode.py`: reconstrucción y descifrado del mensaje desde una captura.

## Herramientas utilizadas

   * Python 3
   * Scapy
   * Wireshark
   * ICMP
   * PCAP/PCAPNG

## Actividades

   Implementación del algoritmo de cifrado César.
   
   Análisis y transmisión de caracteres mediante paquetes ICMP.
   
   Captura y análisis del tráfico generado mediante Wireshark.
   
   Reconstrucción del mensaje y descifrado por fuerza bruta.
